# Mentoris
Plataforma escolar instalable (PWA): tareas, exámenes, anuncios, asistencia, buzón y roles.

- `server.js` — servidor sin dependencias (Node 18+): sesiones, sincronización, archivos, manifiesto/ícono dinámico.
- `lib/storage.js` — Cloudflare R2 (firma SigV4 propia) o carpeta local `data/`.
- `public/` — la app (HTML/CSS/JS).

Guía completa de publicación: **GUIA-RENDER-R2.md**.
